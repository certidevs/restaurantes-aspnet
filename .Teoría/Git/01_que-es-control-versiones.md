# Qué es el control de versiones

> **Control de versiones**: Sistema que guarda los cambios de unos archivos a lo largo del tiempo, para poder volver a cualquier versión anterior

Quizá alguna vez hayas tenido carpetas como `proyecto`, `proyecto_nuevo`, `proyecto_nuevo_final` o `proyecto_final_v2_definitivo`. Esto es una forma casera de guardar versiones, y se complica muy rápido. No se sabe qué cambió entre una copia y otra y, si trabajamos con otra persona, el lío crece.

Un sistema de control de versiones resuelve eso. Guarda cada cambio con su fecha, su autor y un mensaje que lo explica. Podemos volver atrás, comparar dos versiones o buscar quién cambió una línea concreta.

Hay tres tipos de sistemas:

- **Locales**: Guardan el historial en una sola máquina.
- **Centralizados**: Tienen un servidor central del que todos descargan los archivos.
- **Distribuidos**: Cada persona tiene una copia completa del historial. Git es de este tipo.

Con un sistema distribuido, si el servidor se rompe, cualquier copia sirve para recuperarlo.
