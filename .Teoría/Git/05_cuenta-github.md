# Cuenta en GitHub

Para subir nuestros proyectos a GitHub necesitamos una cuenta. Creamos la cuenta siguiendo estos pasos.

1. Entramos en [github.com](https://github.com) y pulsamos **Sign up**
2. Elegimos un nombre de usuario, que aparecerá en la url de nuestros repositorios
3. Confirmamos el email abriendo el correo que nos envían y pulsando el enlace de verificación

Conviene confirmar el email antes de seguir, porque algunas funciones no están disponibles sin verificar.

Conectar nuestro ordenador con la cuenta es un paso aparte. De momento basta con tenerla creada y poder entrar.

Así es la dirección de un repositorio en GitHub.

```text
https://github.com/tu-usuario/proyecto-aspnet
```
