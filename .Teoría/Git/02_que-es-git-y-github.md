# Qué es Git y qué es GitHub

> **Git**: Programa que se instala en nuestro ordenador y guarda el historial de los cambios de un proyecto
>
> **GitHub**: Página web donde guardamos copias de nuestros proyectos de Git en internet

Git se instala en nuestro ordenador. Guarda el historial dentro de una carpeta oculta llamada `.git`. Todo lo que hacemos con Git, como guardar cambios o ver el historial, ocurre en nuestra máquina. Por eso funciona sin internet.

GitHub guarda copias de los proyectos en la nube. A cada proyecto guardado ahí se le llama **repositorio** y podemos compartirlo con otras personas.

GitHub también añade herramientas para trabajar en equipo. Las principales son:

- **Issues**: Sirven para apuntar tareas y errores
- **Pull requests**: Sirven para revisar cambios antes de unirlos
- **GitHub Actions**: Sirve para automatizar tareas

Git es la herramienta que controla los cambios. GitHub es el sitio donde subimos esos cambios para que otros los vean. Hay otros sitios parecidos, como GitLab o Azure DevOps. Podemos usar Git sin GitHub pero no al revés.
